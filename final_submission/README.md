# マイナス金利政策終了前後において、日銀は政策転換をどのように語ったのか

-テキストマイニングpre-提出パッケージ

## 1. プロジェクト概要

本パッケージは、2024年1月から6月にかけて公表された日本銀行の政策声明と講演を対象とする大学テキストマイニング最終課題の再現用資料である。コーパスは日本語の日本銀行文書4件で構成され、自然な段落と文境界を保ちながら約98チャンクに分割した。

## 2. 研究課題

マイナス金利政策終了前後において、日本銀行の政策声明と講演は、一貫した正常化シグナルを発していたのか。

## 3. 対象データ

対象は2024年1月23日と3月19日の政策声明、および2月8日と5月8日の講演である。`data/raw/` に4件のHTML、`data/extracted/` に抽出本文、`data/cleaned/` に最終クリーニング済み本文と `chunks.csv` を収録した。原資料のPDF版は手元に存在しなかったため任意欠落資料として未収録である。

## 4. 2つの候補ストーリー

- Narrative A: マイナス金利政策の終了は、金融正常化への明確な転換として示された。
- Narrative B: マイナス金利政策の終了は、追加的な金融引き締めが直ちに続くとは示されていない

## 5. 使用した3系統の手法

1. TF-IDF: SudachiPyによる日本語解析後、政策声明・講演および時期別の特徴語を比較した。名詞のみTF-IDFは発表用の補助分析である。
2. 埋め込み・クラスタリング: 多言語Sentence Transformerでチャンクをベクトル化し、KMeansの `k=3,4,5` を比較した。
3. 生成AI分類: 固定プロンプトと固定JSONLバッチを用い、政策方向、コミュニケーション機能、確実性を分類した。

文書長の違いによる偏りを抑えるため、主要な文書種別・時期比較には文書均等化集計を用いた。

## 6. ディレクトリ構成

```text
data/                 原資料、抽出・クリーニング済み本文、メタデータ、LLMバッチ
code/pipeline/        実行順に番号を付けた分析スクリプト
code/visualizations.py 既存の結果CSVだけを読む図表再生成スクリプト
notebooks/            実行索引用ノートブック
prompts/              分類時に使用した固定プロンプト
results/              TF-IDF、埋め込み・クラスタリング、生成AI分類の結果
figures/presentation/ 発表用の最終図
figures/supplementary/補足図
```

## 7. 実行環境

Python 3.10以降を想定する。必要ライブラリは `requirements.txt` に記載した。日本語表示には Yu Gothic、Meiryo、Noto Sans CJK JP など、Matplotlibから利用できる日本語フォントが必要である。埋め込みを再生成する場合、初回のみ指定モデルの取得にインターネット接続が必要になる。

## 8. 再現手順

パッケージ直下を作業ディレクトリとして `RUN_ORDER.md` の順に実行する。番号付きスクリプトは提出パッケージの配置に合わせてパス定数のみ調整しており、元スクリプトの分析ロジックは変更していない。既存結果の確認や図の再生成だけであれば、重い前処理・埋め込み生成を再実行せず `python code/visualizations.py` を実行できる。

容量と提出時の見通しを優先し、再現に必須ではない高次元の `tfidf_chunk_matrix.csv` と `tfidf_noun_chunk_matrix.csv` は収録していない。`chunk_embeddings.csv` はPCA図の再現に必要で、容量も妥当なため収録した。埋め込みを再生成する場合は `06_run_embeddings.py` を実行する。

## 9. 生成AI分類について

分類入力は `data/llm_batches/`、固定プロンプトは `prompts/llm_classification_prompt.md`、既存の分類出力は `results/llm/` にある。外部AIによる分類は再現手順上の独立工程であり、結果の閲覧には再実行不要である。分類は固定プロンプトとモデル出力に依存し、話者の意図や実際の市場効果を推論したものではない。

## 10. 主な出力ファイル

- `results/tfidf/`: 通常TF-IDFの特徴語、対比、文書スコア
- `results/tfidf_nouns/`: 名詞のみTF-IDFの補助結果
- `results/embedding/`: クラスタ割当、評価指標、代表チャンク、埋め込み
- `results/llm/`: 元分類、統合表、文書均等化比率、確認候補、代表例
- `figures/presentation/`: 発表用4図
- `figures/supplementary/`: PCA、クラスタ比較、時期比較などの補足図

## 11. 分析上の限界

文書数は4件と小さく、チャンク数が多い文書の影響を完全には除けない。文書均等化はその偏りを軽減するが、標本の代表性を保証しない。TF-IDFは語彙差、埋め込みはモデル上の意味的近さ、生成AI分類はプロンプト依存のカテゴリ判断を表す。いずれも話者の意図や実際の市場効果を直接測定しない。
